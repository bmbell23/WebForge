Personas

Named workspaces with their own tab list and their own hotkey bindings. Opening a URL that matches a Persona's rules switches you to it automatically; anything unmatched lands in Unassigned. Switch with Ctrl+Space then the Persona's number.

One rule per line. Every rule is anchored at the start and open-ended at the end, so https://host also matches https://host/deep/path.
• prefix — https://jira.company.com
• wildcard — https://*.devops.example.com matches any subdomain. * can match nothing, so https://*devops.example.com also covers the bare domain.
• regex — wrap in slashes: /^https:\/\/(ci|cd)\.example\.com/. An invalid pattern simply matches nothing rather than breaking routing.
