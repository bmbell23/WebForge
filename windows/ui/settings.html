Keybindings

Ctrl+Space, then keyFire a bookmark hotkey — jumps to that site's tab; pressed inside it, returns it home. Works while typing. Esc cancels.
Ctrl+TNew tab
Ctrl+W / Ctrl+F4Close tab
Ctrl+Tab / Ctrl+Shift+TabNext / previous tab
Ctrl+PgDn / Ctrl+PgUpNext / previous tab
Alt+← / Alt+→Back / forward
Ctrl+Shift+← / →Back / forward
Ctrl+Shift+UDuplicate tab
Ctrl+Shift+PPin / unpin tab
Ctrl+Shift+WClose all normal tabs (spares pinned + hotkey tabs)
Ctrl+Shift+XClose misc tabs — everything not pinned, hotkeyed, or in a tab group
Ctrl+Shift+DDetach hotkey tab into a normal tab
Ctrl+LFocus address bar
Ctrl+R / F5Reload
F11Toggle fullscreen (hover screen edges to reveal UI)
EscClose dialog / panel / reveal
Ctrl+BBookmarks side panel
Ctrl+Shift+BBookmark manager (opens as a tab)
Ctrl+DBookmark this page (dialog)
Ctrl+Shift+SSettings
Ctrl+Shift+LLock WebForge
Ctrl+QQuit
